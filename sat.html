Scheduling Function (W[i]) This function expands the 64-bit message block, W[i], into a larger set of 64-bit values, used in subsequent rounds. W[i] = W[i ⊕ i+1] ⊕ W[i ⊕ i+1 ⊕ (i+1)] (for i = 0 to 63) Where: ⊕ denotes the bitwise XOR operation. i ⊕ i+1 represents the bitwise XOR of W[i] and W[i+1]. The expression inside the brackets is calculated by XORing the result of i ⊕ i+1 with itself. 2. Round Function (f(X, Y, Z)) This is the core non-linear function used in each round. It’s defined as: f(X, Y, Z) = (X ⊕ Y ⊕ Z) * (X ⋘ a) + (X ⊕ Z) * (Y ⋘ b) + Z Where: ⋘ denotes the left bitwise shift operation (shifting bits to the left by the specified number of positions, filling with zeros on the right). a = 17 (a constant) b = 18 (a constant) 3. Compression Function (Main Loop) This function processes the message block (represented as a, b, c, d, e, f, g, h, i) in 64 rounds, updating these values. Initial Values (Round Constants): h0 = 0x6a09e667 h1 = 0xbb67ae85 h2 = 0x3c6ef372 h3 = 0xa54ff53a Round Iteration (for round i = 0 to 63): Calculate T[i]: T[i] = h + sum(W[i] ⋘ s) + f(h, a, b) Where: s is the round-dependent shift value (s = i mod 64) sum(W[i] ⋘ s) is the sum of all the left-shifted W[i] values. f(h, a, b) is the round function, where h is the current hash value. h = h0, h1, h2, h3 depending on the round number. Update Hash Values: h0 = h1 h1 = h2 h2 = h3 h3 = h0 + T[i]
